# Still Waters Wellbeing — website concept

A responsive, single-page website mockup using the supplied logo and the practice concept PDFs.

## Preview locally
Open `index.html` in a browser. The page uses Google Fonts, and includes locally bundled generated forest/waterfall imagery and logo assets. An internet connection is needed for Google Fonts.

## Publish to a personal GitHub repository
1. Create a new public or private repository, e.g. `still-waters-wellbeing-mockup`.
2. Upload `index.html` and the `assets/` folder (keep the folder structure). The logo is supplied in transparent forest-green and ivory variants.
3. In GitHub, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. GitHub will provide a preview URL when deployment finishes.

## Before this becomes a live practice website
- Replace the stock photography with licensed images and real clinic photographs.
- Confirm Michelle's current professional title, credentials and registration details.
- Confirm current fees, Medicare rebate, eligibility wording, availability and cancellation policy.
- Confirm the correct contact phone number and business email. The supplied PDFs contain inconsistent/old email and phone formatting.
- Have the practice review all service-scope and emergency-support wording.
- Add a reviewed Privacy Policy and connect the enquiry form to a secure, privacy-compliant service. The current form is a non-functional visual prototype and does not transmit or store submissions.
- Add accessibility, SEO, analytics and cookie/privacy settings as appropriate.
